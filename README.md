# Student-Grade-Tracker

A group project - Java Swing app with Derby database.

## What it does
- Add and view students
- Capture and calculate grades
- Generate report.csv
- Export report

## How to operate
1. Download ZIP
2. Go to downloads on your computer
3. Extract the file
4. Open in NetBeans
5. Run the project from src/managementsystem
   -Enter student number and name then press "Add Student"
   -Enter the subject code, name , mark and weight ,then press "Add grade"
   note: This step can be repeated for multiple grade entries
   -Enter attended and total attendance ,then press "Attendance"
   -Press "Report" to display the full report
   - Press "Export Report" to export the report
6. Derby database is in schoolDB folder

## Technologies
Java, Java Swing, Apache Derby, NetBeans
