# Student-Grade-Tracker

A group project - Java Swing app with Derby database.

## What it does
- Add, view, update and delete students
- Capture and calculate grades
- Generate report.csv

## How to run
1. Open in NetBeans
2. Run the project from src/managementsystem
3. Derby database is in schoolDB folder

## Technologies
Java, Java Swing, Apache Derby, NetBeans
